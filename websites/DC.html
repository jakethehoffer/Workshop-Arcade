❓ How to Play

Guess the hidden character in 8 tries. Each guess compares facts: Exact / Partial / No match.
Steps
  1. Pick a character from the bank to see which facts match the target.
  2. Use the search box to narrow by name.
  3. Toggle Match-Only to show only characters that share your matched facts (Partial/Exact). “No match” is ignored in that mode.
  4. Win by tapping the exact character.

Tip: Partial = some overlap; Exact = same set of values.
