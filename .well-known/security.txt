# Workshop Arcade security disclosure policy (RFC 9116).
#
# Workshop Arcade is a static catalog of browser games hosted on
# GitHub Pages. There is no server, no user accounts, and no data
# collection — every game is a sandboxed HTML page that runs in
# the visitor's own browser. Please report any security concern
# (XSS injected via a game submission, supply-chain issue with a
# tooling dependency, policy gap in the Workshop intake flow) via
# GitHub's private security advisories so we can triage and patch
# before any exploit lands in main.
